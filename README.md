# Telegram Bot

ربات تلگرام برای فوروارد پیام کاربران به مدیر و پاسخ‌دهی توسط ادمین.

## نصب (Windows)

```cmd
pip install -r requirements.txt
copy .env.example .env
notepad .env
start.bat
```

## تنظیمات `.env`

```
TELEGRAM_BOT_TOKEN=your_token
ADMIN_USERNAME=MohsenFarhangian
ADMIN_CHAT_ID=1755704405
```

## قابلیت‌ها

- فوروارد پیام کاربران به مدیر
- پاسخ مدیر با Reply روی پیام فوروارد شده
- پیام‌های ربات به کاربران: فارسی (RTL)
- پیام‌های کنسول: انگلیسی
