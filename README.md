# Sql-Server

SQL Server scripts and utilities.

## Telegram Bot

ربات تلگرام (فوروارد پیام + پاسخ مدیر) در پوشه [`telegram-bot/`](telegram-bot/) قرار دارد.

```bash
cd telegram-bot
pip install -r requirements.txt
cp .env.example .env
python -m bot.main
```
